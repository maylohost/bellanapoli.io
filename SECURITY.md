# Security policy

## Supported versions

Security fixes are applied on the default branch (`main`) and released through the normal deployment process for [bellanapoli.io](https://bellanapoli.io). There are no separate long-term support branches.

## Reporting a vulnerability

Please **do not** use public issues for undisclosed security problems.

Report them privately using **[GitHub Security advisories](https://github.com/maylohost/bellanapoli.io/security/advisories/new)** for this repository.

Include enough detail to reproduce or understand the impact (steps, affected components, versions if relevant). We will acknowledge as soon as we can and work with you on a fix and disclosure timeline.

## Out of scope

- Issues that require physical access to a user’s device or wallet seed phrase  
- Social engineering or third-party services outside this codebase  
- Theoretical problems without a practical attack path against deployed configurations  

Thank you for helping keep users and the project safe.
